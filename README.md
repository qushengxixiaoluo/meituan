# 校园食堂点评推荐

> 面向大学生的校园食堂菜品点评与推荐工具，帮你解决「今天食堂吃什么」的决策困境。

`📚 学生作业` `🌱 纯前端` `🍜 模拟数据`

## 产品简介

每天中午站在食堂门口，最难的问题就是「今天吃什么」。大众点评面向社会餐厅，校园场景下既不垂直也不够用。

本项目是一个纯前端原型，聚焦校园食堂场景：帮你**发现新菜**、**避开踩雷窗口**，快速做出今天这一餐的决定。

## 功能特性

- **发现新菜**：新菜尝鲜榜，第一时间看到各窗口上新的菜品
- **避雷预警**：低分预警 + 避雷榜，同学踩过的坑不再踩第二次
- **口碑窗口榜**：按同学点评聚合出的窗口口碑榜单，哪家窗口值得排队一目了然
- **同学最新点评**：同学们最新写下的点评流，随时跟上「吃 / 避雷」风向
- **项目介绍页**：「介绍」tab 用一页讲清项目是什么、能做什么、数据从哪来
- **浏览筛选**：约 4 个食堂 · 12 个窗口 · 40 道菜品 · 66 条模拟评价（数量以 `data.js` 实际为准），支持按食堂/窗口筛选与排序
- **菜品点评**：星级评分 + 口味、性价比打分 + 自由标签
- **我的**：收藏喜欢的菜品，查看自己写过的点评
- **搜索**：按菜名、窗口快速搜索

## 页面结构

- **五个主视图**：首页 / 食堂 / 榜单 / 介绍 / 我的
- **两个弹层**：菜品详情、写点评

## 快速开始

无需构建、无需安装依赖，任选其一：

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：任意静态服务器
python -m http.server 8000
# 打开 http://localhost:8000
```

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建、无外部依赖
- 模拟数据集中在 `data.js`，可直接修改以调整菜品与点评内容
- 点评、收藏保存在浏览器本地，**刷新页面即重置**
